# FitLog V1.3.3：动作改名

2026-10-10。

计划编辑中点击动作旁的“改名”，输入名称后点击“保存计划”生效。同一exercise_id在其他日期同步改名；历史与已创建训练的名称快照保持原样，重量历史、左右侧身份及下次提醒继续按原ID关联。改名用于修正名称，更换为另一种动作应删除计划中的旧动作再新增。

拒绝空名称、超过100字符的名称，以及另一个动作已占用的名称，不合并记录。验证计划动作归属，所有名称与计划更新在事务中执行，失败回滚。未保存或取消改名不修改数据库。无需变更schema，仍为v3，保留V1.3.2升级修复。
